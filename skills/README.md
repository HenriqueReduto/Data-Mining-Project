# Project skills

Store project-specific agent skills here only when a repeatable project workflow warrants one. Each skill belongs in a named subfolder with a SKILL.md. No local skill is required yet.

The user's shared red-project-setup skill maintains the workspace setup workflow. Project rules and teaching preferences live in ../AGENTS.md, confirmed scope in ../docs/project-brief.md, and current work in ../PLAN.md. This folder does not replace those files or automatically install skills into an agent.
